Setup is automatic: the extension fetches its own token from the tool and reconnects on its own. Press this only if something looks stuck — it re-pairs from scratch, which also fixes a token that has gone stale.

The tool only listens while a job is running, so “waiting for the tool” is the normal resting state, not a fault. It connects within a second or two of a run starting.

Observation mode

Every mode submits by clicking. These only control what is recorded while it happens. The replay path was removed on 2026-07-25: the submission carries a ~1,100-character argument the page builds itself, so it can never be learned by watching traffic.
