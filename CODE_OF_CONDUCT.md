# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith and is doing
something reasonable for reasons you cannot see. Argue with the work, not with
the person doing it.

## What is expected

- Criticise code, decisions and claims freely — that is the point of a code
  review, and this project would rather be corrected than agreed with.
- Accept correction the same way. Being wrong in public is the ordinary cost of
  working in the open.
- Take the extra minute to explain *why*. "This is wrong" helps nobody; "this
  drops the remaining URLs when Google throttles" is a contribution.
- Remember that people arrive with different levels of experience, different
  first languages, and different amounts of time. A question you find obvious
  is one somebody had to ask first.

## What is not

Harassment, insults, demeaning comments, or personal attacks. Sexualised
language or imagery. Publishing anyone's private information. Sustained
disruption of discussion. Deliberately filing reports or pull requests in bad
faith.

## Scope

This applies in issues, pull requests, discussions, commit messages and code
review on this repository, and anywhere someone is representing the project.

## Enforcement

Report anything that needs attention to **mr.shahidali.sa@gmail.com**. Reports
are handled privately and the reporter's identity is not disclosed.

Responses run from a private word, through removing comments or commits, to
temporary or permanent bans, depending on what happened. The maintainer decides
and is accountable for it.

This is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), rewritten in this
project's own words.
